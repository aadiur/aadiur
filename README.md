## 🪞 About Me

<img align="right" src="https://raw.githubusercontent.com/devicons/devicon/master/icons/vscode/vscode-original.svg" width="110"/>

I'm **Aadi UR**, a B.Tech Computer Science student at **Amrita School of Computing, Coimbatore** (Class of 2029), focused on becoming a strong **software engineer** with depth in **Data Structures & Algorithms**, **backend engineering**, and **AI/ML**.

My approach to engineering is simple: understand the fundamentals deeply before reaching for the framework. That's why my current priority stack — `C++ → Python → Java → JavaScript → C` — reflects a deliberate path through systems-level thinking, scripting/AI tooling, and application development, in that order of depth.

I'm currently:

- 🧠 Strengthening my **DSA** foundations through consistent, disciplined practice
- 🏗️ Learning **System Design** to think in terms of scalable architecture
- 🤖 Exploring **AI/ML** as an applied engineering discipline, not just theory
- 🔧 Building **Backend + SQL** skills to ship complete, production-style systems

**Open To:** Internship opportunities, open-source contribution, and collaborative student engineering projects.
