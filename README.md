### [3D Rubik's Cube Solver & Dynamic Rerouting Engine](https://github.com/aadiur/Rubiks-cube-solver)

An interactive WebGL 3D Rubik's Cube solver powered by Graph Theory, IDA* Search, and real-time "Google Maps style" route recalculation.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ • WebGL 3D Interactive Cube (Three.js) with smooth slice turn animations    │
│ • IDA* Search Engine & Heuristic State Space Graph Evaluation (f = g + h)   │
│ • Live Google Maps Rerouting: Recalculates shortest path upon wrong moves    │
│ • DSA Telemetry: Real-time search depth, nodes expanded & execution time ms  │
└─────────────────────────────────────────────────────────────────────────────┘
```
